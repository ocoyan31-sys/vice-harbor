An original open-world crime game that runs in a desktop browser from static
files, with no build step and no network request. Explore the sun-soaked
harbour city of Port Brisa on foot and by car: steal rides, dodge or fight the
traffic, take jobs from the harbour's fixers, and shake the police while your
wanted stars climb.

Play it locally: `node serve.ts`, then open http://localhost:8080.
